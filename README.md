# Trace

A minimalist, zen-focused typing experience designed to encourage flow state and mindfulness. There is no failing, no ticking clock, and no leaderboards. Type at your own pace, breathe, and enjoy the wisdom.

## Features
* **Seasonal Atmospheres:** Dynamic visual themes and floating particles tied to the real-world seasons.
* **Time-of-Day Lighting:** Ambient horizon lighting that shifts from dawn, to day, to dusk, to night.
* **Pure Zen Mode:** An option to strip away all punctuation and capitalization for an uninterrupted flow state.
* **Cloud Sync:** Secure authentication and progress tracking using Firebase.
* **Mobile Responsive:** A hidden virtual keyboard trigger allows the sanctuary to be experienced on mobile devices.

## Tech Stack
* **Frontend:** Vue 3, Vite, Tailwind CSS
* **Backend:** Firebase (Authentication & Firestore)
* **Design:** Custom CSS Animations, SVG Filters (Ink Blots & Zen Brushes)

## Getting Started
To run this project locally:

1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`
